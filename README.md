# libast

libast contains the native parsers that the language frontends of the
[Code Property Graph](https://github.com/Fraunhofer-AISEC/cpg) use for languages
whose parser is not available on the JVM. Each parser is built into a shared
library that exposes the AST of the parsed code as C functions, which the CPG
calls through [JNA](https://github.com/java-native-access/jna).

| Directory    | Language | Parser                                                                    | Library        |
|--------------|----------|---------------------------------------------------------------------------|----------------|
| `goast/`     | Go       | [`go/ast`](https://pkg.go.dev/go/ast) and `go/token` of the standard library | `libgoast`     |
| `rustast/`   | Rust     | [rust-analyzer](https://github.com/rust-lang/rust-analyzer), with bindings generated by [UniFFI](https://mozilla.github.io/uniffi-rs/) | `librustast`   |
| `csharpast/` | C#       | [Roslyn](https://github.com/dotnet/roslyn), compiled with .NET NativeAOT  | `libcsharpast` |

## Build

Each directory has a `build.sh` that builds the library for the current
platform. It needs the toolchain of the respective language:

- `goast`: Go (see `goast/go.mod` for the version) and a C compiler for cgo
- `rustast`: a Rust toolchain
- `csharpast`: the .NET 10 SDK and, on Linux, `clang` and the zlib development
  headers that NativeAOT needs

```bash
cd csharpast
./build.sh
```

The result is named `<library>-<arch>.<ext>`, e.g. `libcsharpast-arm64.dylib`.
On macOS, both `arm64` and `amd64` are built.

## Releases

The [build workflow](.github/workflows/build.yml) builds every library for
Linux (`amd64`, `arm64`), macOS (`amd64`, `arm64`) and Windows (`amd64`).
Pushing a tag such as `v1.2.3` publishes all of them as assets of a GitHub
release.

The CPG frontends download the libraries of a fixed release during their build
and ship them in their jar. A change in this repository therefore only reaches
the CPG after a new release and an update of the version in the frontend's
`build.gradle.kts`.
